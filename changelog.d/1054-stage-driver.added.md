A release chain can now be driven, and the driver is the only thing that applies an effect. A stand-down between stages abandons the remaining stages instead of merely stopping the reporting: the control events are read before the next stage is observed, so nothing is looked at and nothing is applied after a stop, and the run receipt names the abandoned stages rather than reporting a count. A run that is waiting owes the same stages under a different word, so a chain that was stood down never reads like one that is still going to finish. `release_chain.harn --plan` reports all of that for a journal without applying anything.
