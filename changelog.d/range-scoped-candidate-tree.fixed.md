The exact-candidate-tree contract now scopes its changelog check to the fragments the candidate's own commit introduced, identifying that candidate from the published immutable attempt whose release notes the tree carries. A fragment that lands on the default branch while a candidate is in flight no longer rejects the candidate on any trigger; it is deferred to the next release and named in the decision's reason. A fragment the candidate itself failed to fold still rejects, and a tree whose candidate cannot be identified keeps the strict contract, defers nothing, and says so.
