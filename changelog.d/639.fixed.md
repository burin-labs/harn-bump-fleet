Tell the operator when a resumed pre-tag checkpoint cannot succeed. A checkpoint runs the release
gate from the tooling frozen in its own tree, so a gate fix that lands on `base` after the pin never
reaches it and every retry fails identically. Recovery now compares the checkpoint's pin against
`base` and, when a release-gate path has changed since, prints the supersede escape — naming the
stale path and the exact `--at-sha <base head>` to retry with, and stating that the immutable attempt
ref is preserved rather than deleted. Finding that escape previously meant reading three library
files.
