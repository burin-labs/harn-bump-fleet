A release retry no longer pays for the exact-tree run/session-view proof before discovering that a failed pre-publication workspace still owns `release/vX.Y.Z`. Cheap owner and stale-branch remediation now runs first, and durable run receipts authorize detaching only the local branch name from that failed workspace while preserving its dirty diff byte-for-byte. Unknown, moved, published, and operator-owned dirty worktrees still fail closed.
