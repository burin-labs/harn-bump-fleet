A downstream bump run that completes successfully without moving any ref to the target is now a typed convergence failure named `run_success_no_target_change`, carrying the pin the repository was left on, the target that was never written, and the bump branch state. Both refs are re-read after the run concludes, so a bump branch that did reach the target still waits for its pull request, and a pin surface that could not be read stays unknown rather than terminating the repository.
