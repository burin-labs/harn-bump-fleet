A runtime bump pull request the fleet approval verifies is now labeled `ship`, so it lands without a person. Before, nothing armed it: the bump workflow publishes it unarmed and then preserves an approved head rather than refresh it. A head approved earlier and never armed recovers on the next approval run. An approval of an older head arms nothing, a `ship` label anyone removed is not put back, and `bump_ship_enabled = false` in the fleet manifest withholds it.
