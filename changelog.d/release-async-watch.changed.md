`release_harn ship-pr` now returns after durable tag, branch, PR, auto-merge, and typed watch-receipt creation instead of synchronously polling GitHub for up to two hours. The separate `watch_harn_release.harn` process resumes from an atomically replaced, schema-validated receipt; it records observed workflow run IDs and recovery dispatch state, requires the finalized checksum/manifest asset contract, re-arms a dropped release PR, and dispatches each successful binary recovery or post-publish cache warm at most once per durable state while leaving failed dispatches retryable.
