Every `regex_captures` call site in this repository is now reached by a test that runs the real function. A census parses each module, decides per site whether a test pipeline reaches the declaration holding it, and reports the pending count with the uncovered names; a site no test reaches fails CI. `regex_captures` returns match objects rather than capture strings, and a caller that misreads that shape behaves exactly like a no-match, which is invisible to the type checker and to any test that stubs the function.
