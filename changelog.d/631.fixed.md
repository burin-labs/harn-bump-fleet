Hash the warmed release binary with the top-level `sha256` builtin instead of a
nonexistent `harness.crypto` namespace. The exact-candidate certification
`platform` lane crashed with `cannot access property \`crypto\` on Harness` the
moment it was first reached, stopping the release after the candidate commit had
already been built, signed, and pushed to `release-attempt/vX.Y.Z/<oid>`. Every
other call site in this package already uses the builtin directly.
