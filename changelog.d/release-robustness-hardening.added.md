Hardened `release_harn.harn` against the failure modes seen during live cuts. A startup self-check fails loud (or auto fast-forwards under `--self-update` / `FLEET_SELF_UPDATE=1`) when the bump-fleet checkout itself is behind its own origin, so a stale harness can no longer run old release code. A deterministic preflight now auto-remediates the known-safe blockers — a stale `release/vX.Y.Z` branch with no open PR and no unique un-pushed commits, and a base branch behind origin with a clean tree — and refuses loudly (never destructively) for anything else. The remote offload gained a publish dry-run command builder and a best-effort coordination hw-post, and the changelog fold now validates the folded `## vX.Y.Z` section against the assembled fragments, recovering deterministically (idempotent re-fold) before any bounded agent massage, which is itself gated so the model can neither invent nor drop fragment content.
