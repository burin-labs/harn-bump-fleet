Fleet projection convergence now retires the proposals it has moved past. Each rendered projection gets a branch named for its exact bytes, so an open `chore: restore fleet-owned projections` pull request on any other such branch is proposing bytes the manifest no longer says; nothing reopened it, and its armed auto-merge could never fire once it conflicted. Every run now closes those with the reason, including proposals left on the single `automation/fleet-projections` branch used before each projection got its own, and including repositories that converge clean — the case that produces the most debris. `--check` names what it would close without closing it, and the convergence receipt carries `superseded_proposals` and `sweep_failed_by` so a sweep that stopped working cannot read like a fleet with nothing to retire. A proposal someone renamed is left alone, as is the branch the current run renders.
