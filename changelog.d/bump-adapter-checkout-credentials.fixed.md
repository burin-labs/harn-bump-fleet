The rendered bump adapter's contract-gate checkout now sets `persist-credentials: false`. A persisted checkout credential writes an unreadable `include.path` into `.git/config`, which makes a later step fail on git configuration rather than on its own work, and consumer repositories refuse a workflow checkout that keeps one. Renderer tests now assert the delegation invariants consumers used to assert for themselves: the bump job delegates to a workflow pinned to a full commit and runs no local steps, the contract gate is the only job that checks out, and its checkout is pinned and credential-free.
