Fleet-owned projection drift now repairs itself. `converge_fleet_projections.harn` renders the same byte-exact projections `check_fleet_policy.harn` reports on, compares them against every target's remote default branch, and proposes the difference as one signed-commit pull request per repository on a stable `automation/fleet-projections` branch. It needs no local checkouts, writes no default branch, and merges nothing. A scheduled `Converge Fleet Projections` workflow runs it with `--apply`; the harness itself reports and exits unless asked to write.
