`lib/github.harn` now validates GitHub responses against the connector's own schemas through `call_typed` instead of asserting record shapes with assignment-only helpers. Public wrappers return the connector's closed contracts rather than `Result<dict, GithubConnectorError>`, so a drifted response fails at the boundary instead of surfacing as a missing field deep in a release or bump run. File reads and latest-release resolution use the connector's typed found-or-absent lookups, which distinguish an accessible repository with no release from one the credential cannot see.
