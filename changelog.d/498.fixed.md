Hosted platform certification no longer dispatches Windows/macOS nightlies
against the moving base branch. Prepare publishes a write-once OID-qualified
`release-certify/<pin>` ref at the frozen release pin first, then dispatches
against that branch, so merges into `main` between pin capture and run creation
cannot break the exact-identity check. The local `release/vX.Y.Z` branch remains
unpublished; only the certification and later `release-attempt/...` refs are
pushed.
