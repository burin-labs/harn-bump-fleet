Ask every release precondition before the release leases anything. A new preflight stage runs first in `audit`, `prepare`, and `ship-pr`, and as its own CI job on every pull request and hourly on main: it validates the dispatch inputs through the release's own validator, mints through the reviewed token profile and asserts the grants the cut will exercise, compares the credential lifetime against the phase wall budgets, and runs the consumer contract gate against live consumer mains, naming the convergence workflow to dispatch on drift. Each precondition is reported pass, fail, or explicitly not asked, so a context that could not ask never reads as one that asked and liked the answer.
