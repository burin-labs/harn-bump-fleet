A release now claims a per-version lane ref in the release repository before it
builds anything, and reports who holds it when the claim is lost. `POST
/git/refs` is atomic across machines, so a hosted run and a local run working
the same version learn about each other at minute one rather than after a full
build. The claim is advisory: it reports and does not block. A lane still held
by this host is reported as abandoned immediately, since the run holding this
host's release lease knows no other release process is running here.
`abandon_release_attempts --apply` consults the same signal, refuses while
another machine holds the lane, and frees the lane along with the version.
