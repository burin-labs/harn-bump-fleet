- Replace name-glob fleet discovery and per-repository schedules with one typed
  `fleet.toml` inventory and one central dispatcher. Package, bump, guidance,
  and connector options now share that authority; missing checkouts, wrong
  remotes, and missing manual bump adapters fail closed.
`fleet.toml` now owns immutable package and bump workflow projections, and the
scheduled dispatcher refuses to fan out when any remote default branch drifts
from those contracts.
The Cloud package index is now a byte-exact, remotely checked projection of
the canonical `harn-packages` registry, and product applications are no longer
misclassified as reusable packages.
Pre-tag binary-size dispatch now persists its exact workflow run identity
before polling and reuses that receipt during recovery instead of dispatching a
duplicate run.
