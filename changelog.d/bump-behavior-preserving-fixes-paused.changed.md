Managed runtime bumps no longer run Harn's unattended behavior-preserving fix pass. That pass rewrites caller-owned source under a safety tier it does not honor (harn#6837), stripping optional-chaining guards from receivers it wrongly proves non-nil. Capability migrations are unaffected, so a bump still carries source compatibility forward. Set `apply_behavior_preserving_fixes` under `[policy]` to restore the pass fleet-wide once that defect is fixed, or `bump_apply_behavior_preserving_fixes` to opt a single repository back in.
