`abandon_release_attempts.harn` frees a release version wedged by leftover attempt refs. Two or more refs under `release-attempt/vX.Y.Z/` leave every recovery route resuming a frozen candidate, so no fix that landed afterwards can reach a gate; each unclaimed attempt is now renamed into `release-failed/vX.Y.Z/<oid>-abandoned` rather than deleted, and a tag, published release, or open PR still blocks the operation.
