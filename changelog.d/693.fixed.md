A release retry no longer meets its own leftover release lane. Nothing frees a
lane on the way out of a release, and nothing can — a run that is killed
mid-build never reaches cleanup — so the claim takes back a lane this host
abandoned instead of reporting it. That state is already proof the holder is
gone: it means the lane is held by the host whose release lease this run holds.
A lane held by any other machine is still never touched.
