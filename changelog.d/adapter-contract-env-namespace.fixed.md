The rendered bump adapter carries its consumer-contract digest under a `FLEET_` environment name instead of `HARN_`. The runtime owns the `HARN_` prefix and aborts with `HARN-ENV-001` on a member it does not know, so the previous name broke any `harn` invocation that inherited it and consumer namespace guards refused the projection outright. A test now asserts over every rendered environment key rather than one name.
